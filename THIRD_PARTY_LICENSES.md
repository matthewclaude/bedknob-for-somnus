## Icon fonts — `dial_font_icons_16.c`, `dial_font_icons_20.c`

- **What:** Generated LVGL bitmap fonts carrying the flame and snowflake
  glyphs originally built for the dial face's boost buttons. **Currently
  unused**: `scr_boost.c` and the boost feature it belonged to were removed
  during the Somnus port, and nothing under `dial_ui/` includes
  `dial_icons.h` or references `DIAL_ICON_FLAME`/`DIAL_ICON_SNOW`/
  `DIAL_ICON_SNOW3` today (confirmed by searching every `dial_ui`/`main`
  source file). The two files are still listed as build sources in
  `dial_ui/CMakeLists.txt`, but neither font symbol appears in a linked
  build's ELF/map (`somnus-dial.elf`/`.map`, spot-checked against a build
  from this same day) — the linker drops them since nothing references them,
  so despite shipping as source, no icon glyph data currently reaches the
  compiled firmware. Kept here rather than deleted: they're still shipped
  source, attribution doesn't depend on whether the linker happens to keep
  something.
- **Where:** `firmware/dial-idf/components/dial_ui/` (glyph macros in the
  now-unused `dial_icons.h`). Two sizes: 16px, 20px. A 26px cut also existed
  during development and was removed once both final sizes were settled.
- **Origin:** Generated by LVGL's `lv_font_conv` from **Bootstrap Icons**
  v1.11.3 (`bootstrap-icons.woff`), taking three private-use codepoints:
  `F7F6` fire, `F56D` snow, `F56F` snow3. Bootstrap Icons is by the Bootstrap
  Authors. An openly licensed set was chosen deliberately: macOS system fonts
  carry equivalent glyphs, but they are not redistributable and this is a
  public repository.
- **License:** MIT.
- **Link:** https://github.com/twbs/icons

## `trust_roots.pem`

- **What:** A curated bundle of 18 public CA root certificates, embedded for
  `dial_ota`'s on-device TLS verification of `api.github.com` and
  `objects.githubusercontent.com` (GitHub's release-asset CDN) — see
  `firmware/dial-idf/components/dial_ota/trust_roots.pem`.
- **Note:** These are public root certificates published by their issuing
  certificate authorities for exactly this purpose (verifying TLS chains).
  Redistributing them for that purpose raises no license concern. The
  bundle originally also verified the upstream project's cloud endpoint for
  `dial_oauth`/`dial_mcp` (the Orion cloud client), and lived at
  `components/dial_oauth/orion_root_ca.pem`. That pipeline was removed in
  the Somnus port — `dial_somnus` talks plain local HTTP, no TLS at all —
  so `dial_ota` is now this bundle's only consumer and it lives at the path
  above instead. Some included anchors (the ones that name Orion's chain
  specifically) are kept as valid roots for other well-known chains rather
  than pruned just because their original reason for inclusion no longer
  applies; see the file's own header comment for the full per-cert
  rationale.
