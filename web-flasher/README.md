# web-flasher

Source of the GitHub Pages browser-flasher site
(https://matthewclaude.github.io/bedknob-for-somnus/). The release workflow
publishes this directory's contents, plus the built merged firmware image,
to this repo's `gh-pages` branch on every `somnus-v*` tag.

`RELEASES-README.md` is the README of the archived
`matthewclaude/somnus-dial-releases` repo, which served this page and the
Releases until `1.0.1` (see `docs/SPEC-repo-consolidation.md` §5, Phase 6).
It is kept here so the frozen-redirect text has a source of record; the copy
on that repo's `main` is what readers see.
